# inverted_search
Inverted Search project implemented in C using Data Structures.
Stores words and the files in which they appear.
Provides efficient word-based searching across multiple files.
Supports creating, displaying, searching, updating, and saving the index.

# Technology Used
C language
Concepts: Data Structures, Hash Tables, Linked Lists, File handling.

# Learnings
Gained practical knowledge of hash tables and linked lists
Improved understanding of files handling in C.
Learned efficient searching and indexing techniques.
Improved Pointers, Structures, and debugging skills.
